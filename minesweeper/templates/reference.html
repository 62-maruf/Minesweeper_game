How to Play

  1. The board is 16 x 16 with 40 hidden mines.
  2. Left click a box to open it. Your first click is always safe.
  3. A number shows how many mines touch that box (including diagonals).
  4. An empty box means no mines nearby, so its neighbors open automatically.
  5. Right click a box to place or remove a red flag 🚩 where you think a mine is.
  6. Open a mine and you lose. Open every safe box and you win.

Tips

  • If a "1" has only one closed box next to it, that box is a mine.
  • If a number already has enough flags around it, the other neighbors are safe.
  • Start in a corner or edge, where there are fewer neighbors to guess.

How This Game Is Built

  • Flask (app.py): keeps the board, places mines, counts neighbors and checks win/lose.
  • HTML + JavaScript (index.html): draws the buttons and sends clicks to Flask with fetch().
  • Flood fill: opening a "0" box uses a stack to open all connected empty boxes.
  • Want to learn more? See the Flask docs and MDN fetch guide.
